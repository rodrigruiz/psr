# psr
Repository dedicated to analyse astronomical time series data

# km3net Branch: Stores code and result plots from Hannes Warnhofer's Masters thesis "Search for Periodic Neutrino Sources with KM3NeT"
## Epoch Folding Analysis:
Constructed was a periodic timing analysis that preprocesses km3net data and selects reconstruced information of events associated with a certain source from a provided set of km3net root files. The files are first processes using the `km3astro.io.root_to_hdf5` utility to calculate high level astronomy data from the low level root data and selects the best reconstruction of the track and shower reco algorithms. Angular reconstruction uncertainty (`workflows/km3net/km3net_angular_resolution/km3net_angular_resolution_workflow.nf`) and energy reconstruction uncertainty (`src/scripts/km3net/MakeEnergyResponseHistogramKM3NeT.py`) is calculated from the MC files. A track/shower classification is applied (using `newhitfeatrues` and `paramPID` to train network on MC files and classifying the root files used in this analysis) and the information of the corresponding reco algorithm is kept (`workflows/km3net/km3net_parampid/km3net_parampid_workflow_data.nf`). Selection cuts are applied and files are combined into a single event list that stores all events from the provided km3net files that are associated with the source of interested. Binary and barycentric correction can be applied. The epoch folding periodic timing analysis can then be applied to detect a possible periodic signal present in this final series of events. This preprocessing is done using the `workflows/km3net/km3net_analysis/km3net_analysis_workflow_creategti_selected.nf`. 
## Sensitivity Study:
Furthermore a sensitvity for this periodic timing analysis was built, which allows to simulate expected events from a specified input flux and sample the arrival times expected from a pulsar timing model. The expected energy and directional reconstructions are sampled. The epoch folding is applied to the final dataset that contains of the simulated data injected into the blinded background dataset as obtained from the real km3net data over the simulated timeframe. To estimate the sensitivty, the maximum chi2 of the epoch folding is analysed for different input fluxes to estimate the minimal required flux that still causes a 5sigma detection of the periodic signal if it is present.   
**Note:** The whole analysis including the sensitivity study was initially constructed in the form of a single nextflow workflow. However, this lead to too many intermediate files being prooduced when looking at sufficiently long timescales and was therefore split up into different parts, unfortunately loosing a bit the order in this repository.
